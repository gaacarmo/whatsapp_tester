Is this number on WhatsApp?
One careful check at a time.

A small local CLI that opens your own WhatsApp Web in a visible browser and tells you whether a number has an account. Built with hard limits, so it stays a spot-check tool and never becomes a scraper.

wa-check · demo

Fictional example numbers. Verdicts are simulated in your browser and pauses are shortened (the real tool waits 8–15 s between checks). Nothing is sent anywhere.

How it works

01

Your session, your machine

Playwright opens a real Chromium window with a persistent profile. You scan the QR code once; the session stays local and is never committed.

02

Validate before touching anything

Every input is parsed with libphonenumber-js. Invalid entries are skipped with a reason, duplicates are removed, and numbers are masked in every log line.

03

Open the chat link, read the page

For each number it opens web.whatsapp.com/send?phone=… and waits for one clear signal: the message box appears, or WhatsApp says the number is invalid.

04

Save as it goes

Each result is appended to results.csv the moment it's known, so Ctrl+C, a crash or a logout never loses finished work.

Three honest answers

●on WhatsApp

The chat opened and the message box is on screen.

○not on WhatsApp

WhatsApp showed its "invalid number" dialog, in any of six languages.

?unknown

Anything else. Slow page, network hiccup, UI change. It never guesses.

Limits, by design

25numbers per run
60checks per rolling 24 h
8–15 spause between checks

Hard ceilings in code. Environment variables can make them stricter, never looser.

Responsible use

  • Only numbers you have a reason to check: your contacts, customers who gave you their number.
  • Automating WhatsApp Web can break its Terms and get the account that runs it restricted. That's why there is no hosted version: this page is a demo, the real thing runs on your machine.
  • Phone numbers are personal data under LGPD and GDPR. Input and result files are git-ignored by default.

Run it locally

$ git clone https://github.com/gaacarmo/whatsapp_tester.git
$ cd whatsapp_tester && npm install
$ npm run demo            # offline, like this page
$ npm run check -- "+55 41 99999-8888"

Node.js 20+. Full setup and options in the README.
